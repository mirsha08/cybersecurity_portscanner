# cybersecurity_portscanner
Proyecto para escaner de puertos y analizador de vulnerabilidades.

Este es un script de automatización en **Python** diseñado para realizar auditorías de red básicas. El objetivo es identificar puertos abiertos en un host específico que podrían representar un riesgo de seguridad.

### 🚀 Funcionalidades
- Escaneo de puertos TCP comunes (FTP, SSH, HTTP, SMB, RDP).
- Identificación de servicios potencialmente vulnerables.
- Gestión de timeouts para optimizar la velocidad de escaneo.

### 🛠️ Tecnologías utilizadas
- **Lenguaje:** Python 3.x
- **Librerías:** `socket` (comunicaciones de red), `datetime`.

### 📝 Cómo usarlo
1. Clona el repositorio.
2. Ejecuta `python scanner_seguridad.py`.
3. Introduce la dirección IP que deseas auditar.

*Nota: Este script ha sido desarrollado con fines educativos y de auditoría ética.*
